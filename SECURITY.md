# Security Policy

## Supported Versions

Only the latest commit on `main` (and the newest PyPI release) receives
security fixes.

## Reporting a Vulnerability

Please report privately — do **not** open a public issue for a vulnerability.

- **Preferred:** GitHub private vulnerability reporting at
  <https://github.com/vegetableno1/DualSPHysics-mcp/security/advisories/new>
- **Backup:** email <529511657@qq.com>, with `[security] dualsphysics-mcp` in
  the subject line.

Include reproduction steps, affected version, and relevant tool output where
possible. Expect an initial reply within a few days; coordinated disclosure
and credit are both fine.

## Scope

This policy covers the Python MCP server in this repository. Vulnerabilities
in DualSPHysics itself (the wrapped solver toolchain) should be reported to
the upstream DualSPHysics project, not here.
